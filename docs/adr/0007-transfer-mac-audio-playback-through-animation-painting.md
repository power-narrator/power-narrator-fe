# Transfer Mac audio playback through animation painting

Changing an audio play effect's StopAfterSlides value through VBA on Mac PowerPoint can degrade unrelated ink replay and fade animations on the same slide. Configure playback in a hidden disposable helper presentation and transfer its animation with PickupAnimation and ApplyAnimation instead of changing that value in the target slide. This avoids adding temporary slides to the author's presentation and keeps presentation edits within VBA.

Reuse the existing audio's animation when it already meets the requested playback settings; new audio with Play Across Slides disabled can use the default play effect. All other cases use the helper, including normalization of custom enabled spans to 999 under ADR 0006. Replacements should change the narration media and app-controlled playback setting while preserving other author settings, including animation behavior, placement, volume, and mute. The existing layout and media defaults apply to new section audio. The helper alone does not preserve custom effects during actual span changes: the setter resets Timing and can delete Pause/Stop and interactive effects. Explicit reconstruction is feasible for tested subsets. Rebuild main-sequence Play/Pause/Stop on the target with effect order restored before Timing; restore effect/behavior duration where required. Self-click behavior can be rebuilt after configuring a plain Play. External-button behavior must be rebuilt against the target slide's button, assigning its trigger to an Appear effect before converting it to Media Play; painting the helper's external interaction loses that relationship.

The 2026-10-16 restoration matrix has 35 exact saved-state matches in 40 replacement/control cases on the two authorized fixture slides, including actual enabling, disabling and custom-span normalization. The five differences are a retained 1 ms sequence-condition change and explicit zero repeat-duration serialization on existing mixed main/click Play effects; slideshow impact remains untested. Arbitrary effects/trigger topology and mixed main/click enabling/normalization are not established.

The approved implementation scope preserves the demonstrated main Play, ordered Play/Pause/Stop, self-click Play, and external-button Play patterns, including supported timing/duration plus volume, mute, and geometry. Reuse matching playback; selectively reconstruct when playback changes. Do not promise arbitrary customization or silently downgrade an unsupported setup. Retain stop/discard/reopen recovery with validation captured before replacement. Investigate the five saved-state differences, cover the missing mixed cases, and assess actual slideshow behavior before declaring the implementation complete; the prior probe matrix is evidence for the design, not completed production acceptance.
