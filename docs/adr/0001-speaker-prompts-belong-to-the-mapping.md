# Speaker prompts belong to the mapping, not the voice

A speaker prompt belongs to a speaker mapping rather than a voice. Delivery is a trait of the speaker ("Alice is the conspiratorial one"), so two speakers sharing one voice must be able to keep independent prompts.

This also preserves the prompt when a speaker temporarily uses a non-promptable voice. Changing voices neither discards the speaker's prompt nor shares it with other speakers using the same voice.

## Consequences

A mapping may retain a prompt while its voice is not promptable. Narration still proceeds without applying that prompt.
