# Slide-note sections remain structured inside the application

PowerPoint note text is the persistence representation of slide-note sections, not the application's working representation. Notes are parsed when they enter from PowerPoint and formatted only when written back; editing, preview, and narration preparation exchange structured sections so note syntax stays at the persistence seam and untouched formatting can be preserved without repeated parse-format cycles. The sole active-session exception is a change to speaker-mapping names: because those names determine which bracketed lines are speaker tags, the editor serializes and reparses current sections, saved baselines, and undo/redo history together once under the new names; ordinary edits, preview, history movement, and narrated save never use that cycle.
